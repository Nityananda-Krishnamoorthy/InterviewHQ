🎯 Interview Strategy

What the interviewer is really looking for — and how to impress them.

Interview Type Analysis

This is a Fresher Technical + HR Round for a Java/Web Developer role. Difficulty: Medium

Interviewers test your conceptual clarity, not deep coding ability. They want to know: Can you learn? Do you communicate well? Do you know your own projects?

Priority List

01OOPs ConceptsMUST
02Project Explanation (own projects)MUST
03Java Basics (JVM, static, final)MUST
04SQL (joins, primary/foreign key)MUST
05REST API + HTTP CodesHIGH
06Self Introduction + HR QuestionsHIGH
07Collections FrameworkHIGH
08Basic Coding LogicMED
09ReactJS / NodeJS (bonus)LOW
10GitHub CommandsLOW

Where Freshers Usually Fail ❌

  • 🔴 Can't explain their own project clearly
  • 🔴 Confuse overloading vs overriding
  • 🔴 Say "I don't know" without attempting an answer
  • 🔴 Speak too fast when nervous
  • 🔴 Memorised answers that sound robotic
  • 🔴 Weak self-introduction (too short or too long)

Anti-Panic Toolkit 🧠

  • ✅ If you forget: Say "Let me think about that" — pause 3 seconds — then answer
  • ✅ If you don't know: Say "I haven't worked with that directly, but my understanding is..." and give what you do know
  • ✅ If you make a mistake: "Actually, let me correct that..." — shows maturity
  • ✅ Breathe: Before entering, take 3 slow deep breaths
  • ✅ Eye contact: Look at the interviewer 70% of the time while speaking
  • ✅ Slow down: Speak at 70% of your normal speed

☕ OOPs Concepts

The #1 most-asked topic for fresher Java interviews. Know these cold.

Class = Blueprint. Object = Instance of that blueprint.

class Car {          // Blueprint
    String brand;
    void drive() { ... }
}
Car myCar = new Car(); // Object (instance)

Interview Answer: "A class is a template that defines properties and behavior. An object is a real-world entity created from that class. For example, Car is a class; myCar is an object of that class."

Hiding internal data by making fields private and exposing them via getter/setter methods.

class Student {
    private String name;  // hidden

    public String getName() { return name; }
    public void setName(String n) { this.name = n; }
}

Real-world: Your ATM card hides your balance internally; you access it via defined methods.

Interview Answer: "Encapsulation means wrapping data and methods together and restricting direct access to the data using access modifiers. We use private fields with public getters and setters."

A child class acquiring properties and methods of a parent class using extends.

class Animal {
    void eat() { System.out.println("Eating"); }
}
class Dog extends Animal {
    void bark() { System.out.println("Woof"); }
}
Dog d = new Dog();
d.eat();  // inherited
d.bark(); // own method

Types: Single, Multilevel, Hierarchical (Java doesn't support multiple inheritance via classes — use interfaces)

FeatureOverloading (Compile-time)Overriding (Runtime)
DefinitionSame method name, different params in same classChild class redefines parent method
BindingCompile timeRun time
Return typeCan differMust be same
Keyword@Overload (not required)@Override
// OVERLOADING
int add(int a, int b) { return a+b; }
double add(double a, double b) { return a+b; }

// OVERRIDING
class Animal { void sound() { System.out.println("..."); }}
class Dog extends Animal {
    @Override
    void sound() { System.out.println("Woof"); }
}

Keywordabstract classinterface

Interview Answer: "Abstraction hides implementation details and shows only essential features. We use abstract class when classes share common behavior, and interface when we want to define a contract for unrelated classes."

    }
}

Default vs Parameterized: Default has no args; parameterized takes args to initialize with specific values.

🔌 REST APIs & Postman

Essential API knowledge for any modern developer interview.

What is a REST API?

A REST API (Representational State Transfer) is a way for two systems to communicate over HTTP using standard methods. The client sends a request; the server responds with data (usually JSON).

Interview Answer: "A REST API is an interface that allows systems to communicate using HTTP methods. The client requests data and the server responds in a structured format like JSON. It's stateless — each request is independent."

HTTP Methods

MethodActionExample URLHas Body?
GETFetch data/api/usersNo
POSTCreate new/api/usersYes
PUTUpdate entire record/api/users/1Yes
PATCHUpdate partial/api/users/1Yes
DELETEDelete record/api/users/1No

Postman is a tool to test REST APIs without writing code. You can send HTTP requests and inspect responses.

Interview Answer: "I use Postman to test API endpoints during development. I can set the method (GET/POST), provide headers like Authorization and Content-Type, add a request body in JSON, and check the response status and data. It saved me a lot of time debugging my Weather App's API integration."

// Sample POST request body in Postman
{
  "name": "Alice",
  "email": "alice@example.com",
  "password": "secret123"
}

Token-based auth: User logs in → server returns a token → client stores token → sends it in headers for every request.

// Authorization header
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5...

JWT = JSON Web Token. It has 3 parts: header.payload.signature. The server doesn't need to store sessions — it just verifies the token signature.

💻 Coding Questions

The most probable fresher coding questions with logic walkthroughs.

Logic: Loop from last character to first, build a new string.

public static String reverseString(String s) {
    String rev = "";
    for (int i = s.length()-1; i >= 0; i--) {
        rev += s.charAt(i);
    }
    return rev;
}
// Input: "hello" → Output: "olleh"

How to explain: "I start from the last index and keep adding each character to a new string."

Logic: A word reads the same forwards and backwards. Compare first half with reversed second half.

public static boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        if (s.charAt(l) != s.charAt(r)) return false;
        l++; r--;
    }
    return true;
}
// "racecar" → true, "hello" → false

Logic: Each number = sum of the previous two. Starts: 0, 1, 1, 2, 3, 5, 8...

public static void fibonacci(int n) {
    int a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        System.out.print(a + " ");
        int temp = a + b;
        a = b;
        b = temp;
    }
}
// n=6: 0 1 1 2 3 5

Logic: A number divisible only by 1 and itself. Check divisibility from 2 to √n.

public static boolean isPrime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i <= Math.sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}
// 7 → true, 9 → false (9%3==0)
import java.util.*;
public static int[] removeDuplicates(int[] arr) {
    Set<Integer> seen = new LinkedHashSet<>();
    for (int x : arr) seen.add(x);
    int[] result = new int[seen.size()];
    int i = 0;
    for (int x : seen) result[i++] = x;
    return result;
}
// [1,2,2,3,3,4] → [1,2,3,4]

Top 20 concepts + quick quiz + pre-interview checklist.

Top 20 Must-Know One-Liners

  1. Class = Blueprint. Object = Instance of blueprint.
  2. Encapsulation = private fields + public getters/setters.
  3. Inheritance = child acquires parent properties via extends.
  4. Overloading = same name, different params, compile-time.
  5. Overriding = child redefines parent method, run-time.
  6. Abstract class can have constructors; Interface cannot.
  7. JVM runs bytecode. JDK = JRE + compiler for development.
  8. static = belongs to class, not instance. Shared across objects.
  9. final variable = constant. final class = can't extend.
  10. ArrayList = fast read (O1). LinkedList = fast insert/delete.
  11. HashMap = key-value pairs. Keys unique; duplicate key overwrites value.
  12. Set = no duplicates. List = allows duplicates.
  13. Primary Key = unique, not null. Foreign Key = links tables.
  14. INNER JOIN = matching rows only. LEFT JOIN = all left + matched right.
  15. DELETE removes rows (can rollback). TRUNCATE removes all rows (no rollback).
  16. GET = fetch. POST = create. PUT = update. DELETE = remove.
  17. 200=OK, 201=Created, 400=Bad Request, 401=Unauthorized, 404=Not Found, 500=Server Error.
  18. JWT = token with header.payload.signature. Stateless auth.
  19. Postman = tool to test REST APIs manually.
  20. When stuck in interview: "Let me think..." → pause → give partial answer → "I'd like to verify this further."

🧠 Quick Quiz

1. What is the difference between ArrayList and LinkedList?
✅ ArrayList = O(1) random access. LinkedList = O(1) insertion at ends but O(n) for get.
2. What HTTP status code means "resource not found"?
✅ 404 = Not Found. 401 = Unauthorized, 400 = Bad Request, 500 = Server Error.
3. Which keyword prevents a method from being overridden?
✅ final on a method prevents overriding. final on a class prevents extension.
4. What does INNER JOIN return?
✅ INNER JOIN = intersection. Only rows with matching keys in both tables are returned.
